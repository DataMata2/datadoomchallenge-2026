# CQA conversation quality review

CQA helps a quality lead discover patterns in conversation quality, inspect the supporting evidence, and record review decisions. This repository contains the DataDoom Challenge 2026 project; the backend and functional frontend prototype are in progress.

The confirmed scope includes:

- A period overview and conversation list with filters.
- Conversation transcripts, call recording access, criterion assessments, score calculations, and source evidence.
- Versioned checklist configuration and tracked evaluation runs.
- Natural-language analysis with saved reports, visible filters, charts, and custom metrics.
- Criterion appeals and reviewer decisions with retained reasons and recalculated results.

The demonstration uses prepared evaluations plus one fresh evaluation. Original source IDs and timestamps remain unchanged; any assigned demonstration dates are separate scheduling metadata with visible provenance.

See the [confirmed product design](docs/coordination/product-discovery/product-design.md) for requirements and constraints. Startup instructions will be added when the implementation is ready to run.
